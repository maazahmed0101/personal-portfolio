2. CSS Magic (The Secret Sauce) Humein translateX (X-axis par move karna) aur opacity (shafafiyat) ka use karna hai. CSS /* Puray page ka overflow-x hidden rakhein taake animation ke waqt side-scroll na aaye */ body { overflow-x: hidden; } .hero-section { display: flex; justify-content: space-around; align-items: center; height: 100vh; } /* LEFT SIDE ANIMATION */ .reveal-left { opacity: 0; /* Shuru mein gayab */ transform: translateX(-100px); /* 100px pichay (left side) */ animation: moveIn 1.2s ease-out forwards; /* 1.2 seconds mein aayega */ } /* RIGHT SIDE ANIMATION */ .reveal-right { opacity: 0; /* Shuru mein gayab */ transform: translateX(100px); /* 100px aagay (right side) */ animation: moveIn 1.2s ease-out forwards; animation-delay: 0.3s; /* Thoda ruk kar aayega, jo cool lagta hai */ } /* COMMON ANIMATION LOGIC */ @keyframes moveIn { to { opacity: 1; /* Poora nazar aaye */ transform: translateX(0); /* Apni asli jagah (0) par aa jaye */ } } Step-by-Step Samjhein Ye Kaise Kaam Kar Raha Hai: opacity: 0 se 1: Jab page load hota hai, element halka sa dhundla hota hai aur phir saaf nazar aane lagta hai (Fade-in effect). transform: translateX: Left wale ke liye humne -100px rakha, yaani wo thoda left se start hoga. Right wale ke liye 100px rakha, yaani wo thoda right se start hoga. forwards (Sabse Important): Agar aap ye nahi likhenge, toh element side se aayega aur phir achanak wapis gayab ho jayega. forwards computer ko batata hai ke: "Bhai, animation jahan khatam hui hai (yaani 100% par), wahi ruke rehna!" animation-delay: Maine image par 0.3s ka delay lagaya hai. Isse kya hota hai ke pehle text aata hai aur uske kuch hi milliseconds baad image aati hai. Isse portfolio zyada professional aur "premium" feel deta hai.
